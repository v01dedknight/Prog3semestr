# Репозиторий по предмету Программирование 3 семестр

## Открывать
Lab0_Task1_Programming.slnx

## Навигация
В Form1 сверху находятся вкладки-кнопки Лаб. 0 ... Лаб. 8.
Лабораторная №4 реализована во вкладке «Лаб. 4».

## Лабораторная №4 — Олимпиадные сортировки
Интерфейс находится в:
Controls/Lab4SortingControl.cs
Controls/Lab4SortingControl.Designer.cs

Через View Designer для Lab4SortingControl.cs отображаются:
- DataGridView для ручного ввода данных;
- параметры генерации;
- поле ссылки Google Table;
- выбор направления сортировки;
- CheckBox для пяти алгоритмов;
- таблица времени выполнения;
- область одновременной визуализации.

Команды, которые не являются непосредственным вводом данных, находятся в MenuStrip:
- Данные -> Сгенерировать;
- Данные -> Загрузить из Excel;
- Данные -> Загрузить из Google Table;
- Данные -> Очистить;
- Сортировка -> Запустить;
- Сортировка -> Остановить.

Реализованы алгоритмы:
- пузырьковая сортировка;
- сортировка вставками;
- шейкерная сортировка;
- быстрая сортировка;
- BOGO.

Поддерживаются сортировка по возрастанию и убыванию, измерение времени каждого
выбранного алгоритма, определение самого быстрого метода и одновременная визуализация.
Для BOGO установлен безопасный предел: не более 8 элементов.

Загрузка Excel поддерживает формат .xlsx. Для Google Table необходимо вставить ссылку
на доступную Google-таблицу, после чего выбрать соответствующий пункт MenuStrip.

Лабораторная №4 — последние правки:
- снято прикладное ограничение на количество элементов (счетчик допускает до Int32.MaxValue);
- генератор создает дробные значения с точностью до 2 знаков;
- итерации считаются по завершенным проходам алгоритмов, а не по отдельным сравнениям;
- для шейкерной сортировки проход туда и обратно считается одной итерацией;
- для BOGO добавлено отдельное поле максимального количества итераций;
- ограничение BOGO по числу элементов удалено, остановка контролируется лимитом итераций;
- визуализация больших массивов прореживается только для отрисовки, сортировка выполняется по всем данным.
