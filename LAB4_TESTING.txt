ЛАБОРАТОРНАЯ №4 — ПРОВЕРКА ПОСЛЕ ПРАВОК

1. Генерация большого количества элементов
   - Откройте Лаб. 4.
   - Укажите 1000, затем 10000 элементов.
   - Данные -> Сгенерировать.
   - Жесткого ограничения 200 элементов больше нет.
   - Для очень больших наборов скорость зависит от выбранного алгоритма и компьютера.

2. Дробная генерация
   - Мин: -10,50
   - Макс: 25,75
   - Количество: 100
   - Данные -> Сгенерировать.
   - В DataGridView должны присутствовать дробные значения с точностью до 2 знаков.

3. Итерации
   Итерация теперь считается как законченный проход алгоритма, а не отдельное сравнение/обмен:
   - Пузырьковая: один проход слева направо по рабочей части массива = 1 итерация.
   - Вставками: одна законченная вставка текущего элемента через его рабочую часть = 1 итерация.
   - Шейкерная: проход слева направо + проход справа налево = 1 итерация.
   - Быстрая: один законченный проход разбиения текущего рабочего диапазона относительно pivot = 1 итерация.
   - BOGO: одно полное случайное перемешивание массива = 1 итерация.

4. Проверка шейкерной сортировки
   - Введите: 5, 4, 3, 2, 1.
   - Выберите только Шейкерную.
   - Запустите.
   - Счетчик должен увеличиваться один раз только после завершения прохода в обе стороны.

5. Отдельный лимит BOGO
   - Выберите BOGO.
   - В поле «Итераций BOGO» укажите, например, 50.
   - Используйте набор: 8, 7, 6, 5, 4, 3, 2, 1.
   - Если за 50 перемешиваний массив не отсортирован, статус должен быть «Достигнут лимит» / «Лимит BOGO».
   - Поставьте 100000 и маленький набор 4, 1, 3, 2 — вероятность успешного завершения существенно выше.

6. BOGO больше не ограничен 8 элементами
   - Можно выбрать BOGO для более длинного массива.
   - Время работы контролируется полем «Итераций BOGO».
   - Для больших массивов задавайте небольшой лимит, иначе BOGO закономерно будет работать долго.

7. Сортировка по возрастанию/убыванию
   - Проверьте набор: 5, -2.5, 10.1, 0, 5.
   - Для каждого алгоритма проверьте оба направления.

8. Большие наборы и визуализация
   - Ограничения на число входных элементов в приложении нет (кроме технического диапазона счетчика int).
   - При большом наборе панель визуализации автоматически прореживает отображаемые точки, чтобы интерфейс оставался пригодным для отрисовки.
   - Сама сортировка работает со всем массивом, а не с прореженной копией.

9. Excel / Google Table
   - Загрузите дробные и целые значения.
   - Убедитесь, что они попадают в DataGridView и сортируются.

10. Ошибки ввода
   - Пустой набор / одно число -> предупреждение.
   - Текст вместо числа -> предупреждение с номером строки.
   - Мин > Макс при генерации -> предупреждение.
