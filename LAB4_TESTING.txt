ЛАБОРАТОРНАЯ №4 — ПРОВЕРКА

1. Генерация
- Лаб. 4 -> Данные -> Сгенерировать.
- По умолчанию должно появиться 20 чисел в DataGridView.
- Поставить Мин = -50, Макс = 100: отрицательные и нулевые значения не должны приводить к падению.
- Поставить Мин > Макс: должно появиться предупреждение, программа не падает.

2. Ручной ввод
- Очистить таблицу и ввести: 5, -2, 10, 0, 5.
- Допускаются отрицательные значения, ноль, дубликаты.
- Ввести текст abc: при запуске должна появиться ошибка с номером строки.
- Оставить только одно число: должно появиться сообщение, что требуется минимум два.

3. Алгоритмы
- По очереди проверить: Пузырьковая, Вставками, Шейкерная, Быстрая.
- Затем включить сразу несколько CheckBox: визуализации должны идти одновременно.
- Снять все CheckBox и запустить: должно появиться предупреждение о необходимости выбрать алгоритм.

4. Возрастание / убывание
- Для набора 5, 1, 4, 2, 3 проверить Возрастание.
- Затем тот же набор проверить с Убывание.
- Все выбранные алгоритмы должны закончить работу без ошибок.

5. Время и самый быстрый
- После запуска в таблице "Время сортировки" должна быть строка для каждого выбранного алгоритма.
- У каждой завершенной сортировки должен быть статус "Выполнено".
- Ниже должна отображаться строка "Самый быстрый: ...".

6. BOGO
- Ввести 4-6 чисел, включить только BOGO и запустить.
- Проверить оба направления сортировки.
- Ввести 9 чисел и включить BOGO: должно появиться предупреждение, что BOGO допускает не более 8 значений.
- Если BOGO выполняется долго, использовать Сортировка -> Остановить.

7. Остановка
- Сгенерировать 100-200 чисел, поставить задержку 30-50 мс, выбрать несколько обычных алгоритмов.
- Запустить, затем Сортировка -> Остановить.
- Интерфейс должен разблокироваться, статус должен сообщить об остановке.

8. Очистка
- После генерации/сортировки выбрать Данные -> Очистить.
- DataGridView, результаты, визуализации и Google URL должны очиститься.

9. Excel
- Создать .xlsx, на первом листе разместить числа, например: 9, 3, -4, 7, 0.
- Данные -> Загрузить из Excel... -> выбрать файл.
- Числа должны появиться в DataGridView; затем выполнить сортировку.
- Проверить .xlsx без чисел: программа должна показать понятную ошибку.

10. Google Table
- Создать Google Sheets с числами и включить доступ по ссылке.
- Вставить URL в поле Google Table URL.
- Данные -> Загрузить из Google Table.
- Числа должны появиться в DataGridView; затем выполнить сортировку.
- Проверить пустой URL, неправильный URL и закрытую таблицу: приложение должно показать ошибку, а не завершиться аварийно.

11. Граничные данные
- Ровно 2 числа: сортировка работает.
- 200 чисел: сортировка работает.
- Более 200 чисел при ручном вводе/импорте: появляется предупреждение о лимите визуализации.
- Одинаковые числа, уже отсортированный набор, отрицательные числа и ноль: приложение работает корректно.
