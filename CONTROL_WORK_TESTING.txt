КОНТРОЛЬНАЯ РАБОТА: КВАДРАТНЫЕ УРАВНЕНИЯ
============================================================

Проект: Lab0_Task1_Programming.slnx (C# WinForms, net10.0-windows).
В верхнем меню выберите «Контрольная». Отдельную программу запускать не нужно.

ИНТЕРФЕЙС
- Поля a, b, c задают уравнение ax² + bx + c = 0.
- Расчёт -> Решить (или Enter в поле) — выполнить решение.
- Расчёт -> Очистить — очистить ввод и результаты.
- Примеры — несколько тестовых уравнений.
- Слева: пошаговое решение через дискриминант, ниже проверка по Виету.
- Справа: парабола (или прямая при a=0), вершина и действительные корни.

КОНТРОЛЬНЫЕ СЛУЧАИ
1) a=1, b=-5, c=6    D=1     x1=2, x2=3
   Виет: сумма=5, произведение=6; обе проверки совпадают.
2) a=1, b=-2, c=1    D=0     x=1 (двукратный)
   Виет: сумма=2, произведение=1.
3) a=1, b=2, c=5     D=-16   действительных корней нет
   Комплексные корни: -1+2i и -1-2i; Виет работает и для них.
4) a=0,5 b=-1,5 c=1 D=0,25  корни 1 и 2
   Проверьте дробные коэффициенты с запятой и точкой.
5) a=1, b=0, c=-4    D=16    корни -2 и 2
6) a=0, b=2, c=-4    линейное уравнение x=2; Виет неприменим.
7) a=0, b=0, c=0     любое действительное x — решение.
8) a=0, b=0, c=3     решений нет.
9) a=1, b=100000000, c=1  корни около -100000000 и -0,00000001.
   Точная формула вычисления корней снижает ошибку вычитания близких чисел.
10) a=0,1 b=0,2 c=0,1 двойной корень x=-1
    Пример проверки округления дискриминанта при двоичном представлении дробей.

ПРОВЕРКИ ОШИБОК
- Пустое поле, «abc», «NaN», «Infinity», неверный формат => понятное сообщение,
  приложение не должно аварийно завершаться.
- При больших числах, приводящих к переполнению double, появляется предупреждение
  с рекомендацией нормализовать коэффициенты.
- По очереди откройте Лаб. 0, Лаб. 1, Лаб. 2, Лаб. 3, Лаб. 4 и вернитесь
  к «Контрольной», чтобы убедиться, что существующие вкладки работают.

ТЕОРИЯ
D = b² - 4ac.
D>0: два действительных корня; D=0: один двукратный; D<0: два комплексных.
При a != 0: x1+x2 = -b/a; x1*x2 = c/a.
Теорема Виета здесь служит проверкой результатов формулы дискриминанта.

СБОРКА
Откройте solution в Visual Studio 2026 с .NET 10 Desktop SDK.
Сборка -> Перестроить решение. Для редактирования интерфейса:
Controls/QuadraticEquationControl.cs -> ПКМ -> Просмотреть конструктор.

Примечание: в среде создания архива нет .NET SDK для реальной WinForms-сборки;
структура и обработчики проверены статически, прогон на Windows нужен.
