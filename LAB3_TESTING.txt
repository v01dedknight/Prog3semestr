ЛАБОРАТОРНАЯ №3 — МЕТОД НЬЮТОНА
================================
Лаб. 2 (золотое сечение) НЕ изменялась. Лаб. 3 — отдельная лабораторная.

Как открыть: Visual Studio → Lab0_Task1_Programming.slnx → F5 → «Лаб. 3».
Для конструктора: Controls/Lab3NewtonControl.cs → ПКМ → Просмотреть конструктор.
Для кода: F7.

Сценарии проверки:

1. ОСНОВНОЙ МИНИМУМ
   Режим: Минимум
   f(x) = x^2-4*x+5
   a=-2, b=6, e=0,0001, x0 пусто
   Ожидается x≈2, f(x)≈1.
   Пошагово → Первый шаг, затем Следующий шаг: точка движется к минимуму.
   Изменение ползунка также обновляет график и выделенную строку таблицы.

2. МАКСИМУМ
   f(x) = -(x-2)^2+5; a=-2, b=6, e=0,0001
   Режим: Максимум. Ожидается x≈2, f(x)≈5.

3. ОБА ЭКСТРЕМУМА
   f(x) = sin(x); a=0, b=7, e=0,0001
   Режим: Оба экстремума.
   Возможные точки: максимум ≈1,5708; минимум ≈4,7124.
   «Траектория» переключает, чьи шаги показывать.

4. НЕСКОЛЬКО ЭКСТРЕМУМОВ
   f(x) = sin(x); a=0, b=15, e=0,0001
   Ожидается предупреждение о нескольких найденных экстремумах.
   Для выбора конкретного введите x0 вблизи желаемой точки.

5. МОНОТОННАЯ ФУНКЦИЯ
   f(x) = x; a=0, b=5, e=0,01
   Нет внутреннего экстремума; программа сообщает о граничных значениях.

6. РАЗРЫВ ИЛИ НЕОПРЕДЕЛЁННОСТЬ
   f(x) = 1/x; a=-1, b=1, e=0,001
   Программа не должна объявлять разрыв в x=0 минимумом.

7. ОШИБКИ ВВОДА
   a >= b; e <= 0; пустая f(x); f(x) = abc(x); x0 вне [a,b].
   Ожидаются понятные сообщения без аварийного закрытия приложения.

8. ОТДЕЛЬНЫЙ ГРАФИК
   Измените f(x), нажмите График → Построить график.
   Затем Расчёт → Рассчитать и проверьте появление траектории.

9. ОКРУГЛЕНИЕ
   При e=0,01 ответы x и f(x) показываются до 2 знаков после запятой.
   В таблице шагов значения сохраняются более точными (до 9–12 значащих цифр).

ПРИМЕЧАНИЯ ПО МЕТОДУ
Метод Ньютона использует x_(n+1)=x_n-f'(x_n)/f''(x_n).
Первая и вторая производные вычисляются численно пятиточечными формулами.
Для сложных функций метод может не сойтись; защитный шаг делит изолированный
интервал пополам. Золотое сечение в этом модуле не используется.
Численное дифференцирование ограничивает достижимую точность; нельзя
гарантировать экстремум для всех функций и интервалов.
