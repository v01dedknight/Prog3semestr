Исправления сборки лабораторной №3 — Метод Ньютона

1. Lab3NewtonControl.Designer.cs:
   - В строке размещения подписи x0 удалён вызов отсутствующего CreateLabel(...).
   - Используется уже созданный элемент initialLabel.

2. NewtonExtremumSolver.cs:
   - Удалены два недостижимых catch (OverflowException), стоявшие после
     catch (ArithmeticException). OverflowException является подклассом
     ArithmeticException и уже обрабатывается им.

3. Все семь файлов *.Designer.cs:
   - Добавлена директива #nullable enable, устраняющая предупреждения CS8669,
     связанные с nullable-аннотациями в автоматически создаваемых файлах.

4. Рекомендация анализатора «Использовать основной конструктор» — это
   необязательная подсказка по стилю (не ошибка компиляции).

Как проверить:
- Открыть Lab0_Task1_Programming.slnx в Visual Studio.
- Выполнить «Сборка -> Перестроить решение».
- Запустить приложение, перейти в «Лаб. 3», выбрать минимум
  для f(x)=x^2-4*x+5, a=-2, b=6, e=0,0001.
- Ожидаемый результат: x ≈ 2, f(x) ≈ 1. Проверить пошаговую визуализацию.

Примечание: .NET SDK и Windows Forms недоступны в среде обработки,
поэтому фактическую сборку на Windows необходимо выполнить локально.
