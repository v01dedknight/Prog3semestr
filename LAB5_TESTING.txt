Где находится: вкладка «Лаб. 5» основного приложения.
Основной интерфейс: Controls/Lab5IntegrationControl.cs + .Designer.cs
Расчёты: Controls/IntegralNumerics.cs

ФУНКЦИИ
- Левые прямоугольники
- Правые прямоугольники
- Средние прямоугольники
- Трапеции
- Метод Симпсона (параболы)

ТРЕБОВАНИЯ МЕТОДИЧКИ
- Ввод f(x), a, b, n, e — в TextBox.
- Множественный выбор методов — CheckBox. Все выбранные считаются за один запуск.
- Генерация случайных корректных исходных данных — меню «Расчёт».
- Все команды, включая очистку, построение и генерацию, находятся в MenuStrip.
- График функции и изображение геометрических разбиений — справа.
- История последовательного уточнения n — нижняя левая таблица, кликом по строке
  либо ползунком можно переключать на любые предыдущие разбиения.
- Оценка точности — метод Рунге при последовательном удвоении n.
- Для Симпсона n приводится к ближайшему большему чётному целому.
- Можно открыть крупное изображение графика в отдельном окне через меню «Расчёт».

ВАЖНО ПРО n И e
n — начальное количество разбиений; при уточнении увеличивается вдвое.
e — порог АБСОЛЮТНОЙ оценки погрешности Рунге:
  abs(I(2n)-I(n)) / (2^p-1) <= e,
  p=1 для левых/правых прямоугольников;
  p=2 для средних прямоугольников/трапеций;
  p=4 для Симпсона.
Выводится найденное n и результат на соответствующем шаге.
«Оптимальное» означает первое n в последовательности n, 2n, 4n, ...,
выполнившее критерий Рунге; это НЕ доказательство глобально минимального n.
Оценка предполагает достаточно гладкую функцию. При разрывах/особенностях
автоматическая гарантия точности математически не предоставляется.

КОНТРОЛЬНЫЕ ПРИМЕРЫ
1) f(x)=x^2, a=0, b=1, n=8, e=0,0001
   Точное значение 1/3 = 0,333333333333...
   Ожидаемая оценка n: Левые/Правые 8192, Средние 32,
   Трапеции 64, Симпсон 16. Все ответы близки к 1/3.
2) f(x)=sin(x), a=0, b=3,141592653589793, n=8, e=0,0001
   Точный интеграл 2.
3) f(x)=exp(x), a=0, b=1, n=8, e=0,0001
   Точный интеграл e-1 ≈ 1,718281828459.
4) f(x)=x^2, a=1, b=0, n=8, e=0,0001
   Интеграл отрицательный: -1/3.
5) f(x)=x^2, a=1, b=1: интеграл 0.
6) f(x)=sqrt(x), a=-1, b=1: программа должна сообщить о точках,
   в которых значение функции не определено, а не выдавать фальшивое число.
7) Некорректные данные: n=0, n=3.5, e=0, e=-0.01, пустая формула,
   незакрытая скобка; должны показываться понятные сообщения об ошибке.
8) Число n=7 и выбран только метод Симпсона: первый шаг истории — n=8.
9) Выбрать все пять CheckBox, рассчитать, выбрать метод в верхней левой
   таблице, затем начальный/промежуточный/последний шаг в истории.
10) «Расчёт → Сгенерировать данные» — заполняет корректные случайные
    значения; результаты появляются после команды «Рассчитать».

ПОЯСНЕНИЕ ДЛЯ ЗАЩИТЫ
Каждый метод разбивает [a,b] на n частей и приближённо вычисляет площадь
со знаком под графиком f(x). Для контроля точности вычисляем значение
при n и 2n разбиениях. По правилу Рунге оцениваем погрешность нового
результата. Увеличиваем n, пока оценка не станет <= e. В таблице
показаны результаты каждого метода; в истории — все предыдущие попытки.
